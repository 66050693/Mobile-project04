# 📱 Mobile AI Recommender

ตั้งงบ (บาท) และการใช้งาน → ระบบเลือก **5 รุ่นที่เหมาะที่สุด** พร้อมข้อดี/ข้อควรรู้จากสเปกจริง กราฟเทียบจุดเด่น และคลิปรีวิว YouTube
เน้นรุ่นที่ขายอย่างเป็นทางการในไทย และขยายไปดูทุกรุ่นในฐานข้อมูลได้

## ระบบทำงานอย่างไร
```
data/smartphones_2026.csv (Kaggle, 997 แถว) ──► รวมรุ่นย่อย → 665 รุ่น
data/specs_thai_extra.csv (สเปกจากเว็บทางการ 18 รุ่นที่ dataset ไม่มี)
thailand_catalog.json (81 รุ่น 10 แบรนด์ที่ขายในไทย) ──► จับคู่ชื่อรุ่น (ครบทุกรุ่น)
data/prices.csv (ราคาไทยที่ตรวจเอง) ──► ถ้าไม่มี ใช้ราคาอินเดีย × อัตราแลกเปลี่ยน (ระบุว่า "ประมาณ")
                         │
ผู้ใช้: งบ / การใช้งาน / ด้านที่เน้น / ตัวกรอง
                         ▼
กรอง → ให้คะแนนรายด้าน 0–100 (percentile) → ถ่วงน้ำหนักตามการใช้งาน → + ความคุ้มค่า → 5 อันดับ
                         ▼
Gemini เขียนคำอธิบายจาก 5 รุ่นนี้เท่านั้น (ตรวจชื่อรุ่น, ไม่มี key ใช้คำอธิบายจากสูตร) + รีวิว YouTube
```
**AI ไม่ได้เลือกรุ่นหรือเดาตัวเลข** การจัดอันดับเป็นสูตรที่ตรวจสอบได้ AI ทำหน้าที่อธิบายเป็นภาษาคน

## ฟีเจอร์
- **พิมพ์บอกเป็นประโยค** เช่น “งบไม่เกินหมื่น เล่น ROV ลื่น แบตอึด” ระบบตั้งงบ การใช้งาน และตัวกรองให้ (Gemini ถ้ามี key ไม่งั้นใช้กฎภาษาไทย)
- **5 อันดับพร้อมรูป** ข้อดี/ข้อควรรู้ คะแนนความเหมาะสม และคลิปรีวิว
- **ราคาเทียบความเหมาะสม** กราฟทุกรุ่นในงบ พร้อมเส้นความคุ้มค่า
- **ถ้าเพิ่มงบอีกนิด** บอกว่าเพิ่ม 2,000/5,000 บาทแล้วได้รุ่นไหนที่ดีขึ้นชัดเจน
- **ทำไมไม่ใช่รุ่นนี้?** อธิบายว่ารุ่นที่สนใจตกตัวกรองอะไร หรือแพ้อันดับ 5 ด้านไหน
- **ถาม AI ต่อ** แชทแบบ Agent ที่เรียกเครื่องมือคำนวณจริง ถ้าไม่มี GEMINI_API_KEY หรือ Gemini ล่ม จะตอบจากข้อมูลในระบบแทน (`chat_rules.py`)
- **เทียบเอง / ดูทุกรุ่น** เลือก 2–3 รุ่นมาเทียบ หรือค้นหาทั้งฐานข้อมูล

## หน้าตา (v11)
- พื้นหลังทุกหน้าใช้ palette #353A5F → #9EBAF3 แบบเบลอจางๆ กรอบต่างๆ เป็นกระจกฝ้ามองทะลุเห็นพื้นหลัง
- หน้าล็อกอินเป็นกรอบขาว ตัวอักษรดำ ฝั่งขวาเป็นภาพคลื่นกระดาษไล่สีตาม palette (วาดด้วย SVG ในโค้ด)
- แถบเมนูด้านข้างสีขาว กางออกเห็นไอคอน+ชื่อเมนู หุบแล้วเห็นแค่ไอคอน มีโปรไฟล์วงกลมกับอีเมล และปุ่มออกจากระบบอยู่ล่างสุด
- ตารางเทียบสเปกมีเงาให้นูนเป็น 3 มิติ กราฟอยู่บนกระจกขุ่นกว่าเล็กน้อยเพื่อให้สีอ่านชัด

## Machine Learning (แท็บ “โมเดล ML”)
- **Random Forest Regression** ทำนายราคาที่ควรเป็นจากสเปก (เป้าหมาย log ราคา) แบ่ง train/test 80/20
  ผลบนชุดทดสอบ: R² ≈ 0.87, MAPE ≈ 19% เทียบ baseline (ทายด้วยค่ามัธยฐาน) R² ≈ −0.07, MAPE ≈ 67%
  ราคาที่ควรเป็นของแต่ละรุ่นใช้ 5-fold cross-validation (รุ่นนั้นไม่ได้ใช้สอนโมเดลที่ทายตัวเอง)
  ใช้ติดป้าย “ถูก/แพงกว่าสเปก” และเป็นคะแนนความคุ้มค่าในการจัดอันดับ อธิบายโมเดลด้วย permutation importance
- **K-Means Clustering** แบ่งกลุ่มมือถือ เลือกจำนวนกลุ่มด้วย silhouette score ตั้งชื่อกลุ่มอัตโนมัติ แสดงด้วย PCA 2 มิติ
- ค่าผิดปกติใน dataset (เช่น ชาร์จ 11,200W) ถูกตัดเป็น “ไม่มีข้อมูล” ก่อนเทรน

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `app.py` | หน้าเว็บ: หามือถือ, เทียบเอง, ราคาไทย, ข้อมูลและวิธีคิด |
| `ui.py` | ธีม CSS และชิ้นส่วน UI (การ์ด ป้ายราคา แถบคะแนน ชิป) |
| `config.py` | path ไฟล์ ค่าตั้งต้น และการอ่าน secrets |
| `dataset_service.py` | โหลด dataset, รวมรุ่นย่อย, คะแนนชิป, ราคา |
| `thailand_filter.py` | รายชื่อรุ่นในไทย + จับคู่ชื่อรุ่น |
| `scoring_service.py` | กรอง ให้คะแนน ข้อดี/ข้อควรรู้ |
| `ai_service.py` | Gemini อธิบายผล + ตรวจคำตอบ |
| `assistant_service.py` | แปลงคำขอภาษาพูด + แชท Agent/Tools |
| `ml_service.py` | Random Forest ราคาที่ควรเป็น + K-Means แบ่งกลุ่ม |
| `insight_service.py` | ทำไมไม่ใช่รุ่นนี้, เพิ่มงบ, เส้นความคุ้มค่า |
| `chat_rules.py` | ตอบแชทจากข้อมูลในระบบเมื่อไม่มี/เรียก AI ไม่ได้ |
| `youtube_service.py` | คลิปรีวิว YouTube |
| `firebase_auth.py` | ล็อกอิน สมัคร รีเซ็ตรหัสผ่าน |
| `tests/test_core.py` | ทดสอบอัตโนมัติ (ไม่ต้องมี key) |

## ปรับข้อมูล
- **ราคาไทย**: แก้ในแท็บ “ราคาไทย” → ดาวน์โหลด → แทนที่ `data/prices.csv` ใส่วันที่และที่มาทุกครั้ง
- **รูปมือถือ**: ใส่ลิงก์รูปใน `data/images.csv` (คลิกขวารูปบนเว็บแบรนด์ → คัดลอกที่อยู่รูปภาพ) รุ่นที่ไม่มีรูปหรือลิงก์เสียจะแสดงรูปสำรอง
- **รุ่นที่ขายในไทย**: แก้ `thailand_catalog.json`
- **รุ่นที่ dataset ไม่มี**: เพิ่มแถวใน `data/specs_thai_extra.csv` (คอลัมน์เหมือน dataset ไม่ต้องมีราคา ใส่ลิงก์ source)
- **สเปกที่ dataset ไม่มี**: เติมใน `data/specs_manual.csv` (คอลัมน์ brand, model และสเปกที่ต้องการ เช่น camera_mp)
- **อัตราแลกเปลี่ยน**: ตั้งในแถบข้าง (ค่าเริ่มต้นใน `config.py`)
